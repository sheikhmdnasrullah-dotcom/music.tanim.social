# Music model license record

This project does not download model weights automatically. Code repositories and model weights can have different terms, so a provider is not marked available until its service owner verifies the exact revision and weights.

| Provider | Code source | Weight/source status | Project policy |
| --- | --- | --- | --- |
| YuE2 | [himomohi/yue](https://github.com/himomohi/yue) | Must be verified from the selected release/model terms; do not assume Apache code terms cover weights | Keep generation behind a configured service and preserve the canonical song |
| ACE-Step 1.5 | [ACE-Step/ACE-Step-1.5](https://github.com/ACE-Step/ACE-Step-1.5) | Must be verified for each downloaded checkpoint and intended commercial use | Do not download or expose a checkpoint until terms are recorded |
| DiffSinger | [wiwomu/diffsinger](https://github.com/wiwomu/diffsinger), [OpenVPI community implementation](https://github.com/Waldo-Schaeffer/openvpi-DiffSinger) | Singer models, datasets, and vocoders require separate review | Only use a singer model with verified redistribution/use rights |

The canonical lyrics, melody, timing, and existing audio are project-owned source material and must never be overwritten by generated output.
